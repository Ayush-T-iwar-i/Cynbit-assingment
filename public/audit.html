How this page was improved

I audited the contact page on cynbit.in in Chrome DevTools, on a phone-sized screen. Cynbit’s goal is to turn visitors into inquiries, so I rebuilt that path end to end.

What the audit found, and what changed

Findings from the original site and the fix in this prototype
FindingEvidenceFix in this prototype
12 form fields without labelsDevTools Issues panelEvery field has a linked label, so screen readers announce it.
4 fields missing autocompleteDevTools Issues panelName, email and organization use the right autocomplete values for one-tap autofill.
Hero image returning 404Console: GET /_next/image 404No remote images, so there is nothing to break.
Lazy image without dimensionsDevTools Issues panelNo layout shift: the layout does not depend on loading images.
108 requests on first loadNetwork tab, many _rsc prefetchesA small static page with a handful of requests.
Tiny, low-contrast labels and grey buttonsVisual review at mobile widthLabels at 15px or larger, body text at 17px, colors tuned for WCAG AA in both themes.
Header always on screenMobile viewHides when scrolling down, returns when scrolling up.
Light theme onlyVisual reviewDark and light themes that follow the system and remember the choice.

What was built

  • An accessible inquiry form with server-side validation, spam trap and rate limiting.
  • A MongoDB-backed API that stores every inquiry.
  • An admin dashboard with search, filters, notes, status workflow, CSV export and a 7-day trend.
  • AI lead triage that labels each inquiry with a category, priority and one-line summary.
  • A streaming support chatbot that only states verified company facts and hands off to the team otherwise.
  • Automated API tests and optional email notification for new leads.

Stack

Node.js, Express, MongoDB with Mongoose, Claude API, and plain HTML, CSS and JavaScript. No build step, so the page loads fast and is easy to port into the Next.js site.
